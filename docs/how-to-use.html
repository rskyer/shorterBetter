Note: Works in both browser and Node.js environments. All functions are available globally in the browser or via require/import in Node.js.
Core Utilities
getElementsById(ids) ids: string
Maps multiple element IDs to their DOM elements. Returns an array of elements.
its so usefull when want to have one ... ten numbers and get elements in just 1 line
Example 
const [header, footer] = getElementsById('header', 'footer');
Returns: Array<Element> — Array of DOM elements
clog(texts) text: any alias
Shortcut for console.log(). Also available as consoleLog() and cLog().
Example 
clog('Hello world');
Returns: void
cerr(...text) text: any alias
Shortcut for console.error(). Also available as cErr().
Example 
cerr('An error occurred');
Returns: void
textContent(id, ...text) id: Element, text: string
Sets the text content of a DOM element. Handles errors gracefully.
Example 
textContent(document.getElementById('output'), 'Updated text');
Returns: void
Console Styling
colorConsoleLog(...args) text: any, color: string
Logs text to the console with ANSI color styling. Supports named colors and hex codes.
Example 
colorConsoleLog('Success!', 'green');
colorConsoleLog('Error', '#ff0000');
Returns: void
cclog(...args) text: any, color: string alias
Alias for colorConsoleLog(). Also available as colorClog().
Example 
cclog('Warning', 'yellow');
Returns: void
Process Control
Proccess.exit() static
Exits the current process. Works in Node.js environment.
Example 
Proccess.exit();
Returns: void
begin() pascal style
Marks the start of code execution with a green console message.
Example 
begin();
Returns: void
end() pascal style
Marks the end of code execution and exits the process.
Example 
end();
Returns: void
Pascal Style Helpers
write(...text) text: any alias
Alias for console.log(). Also available as writeLn().
Example 
write('Hello');
Returns: void
reWrite(...text) text: any pascal style
Returns the input text as-is. Useful for chaining.
Example 
const result = reWrite('Hello', 'World');
Returns: Array — The input arguments
coloredWriteLn(...args) text: any, color: string alias
Alias for cclog() with Pascal-style naming.
Example 
coloredWriteLn('Hello', 'blue');
Returns: void
Math & Random Utilities
sleep(ms) ms: number
Returns a promise that resolves after the specified milliseconds.
Example 
await sleep(1000);
Returns: Promise<void>
rand(min, max) min: number, max: number
Returns a random integer between min and max (inclusive).
Example 
const num = rand(1, 10);
Returns: number — Random integer
randFloat(min, max) min: number, max: number
Returns a random float between min and max.
Example 
const num = randFloat(1.5, 5.5);
Returns: number — Random float
pick(arr) arr: Array
Returns a random element from the array.
Example 
const item = pick(['a', 'b', 'c']);
Returns: any — Random array element
shuffle(arr) arr: Array
Returns a shuffled copy of the array using Fisher-Yates algorithm.
Example 
const shuffled = shuffle([1, 2, 3, 4]);
Returns: Array — Shuffled array
unique(arr) arr: Array
Returns an array with duplicate values removed.
Example 
const uniq = unique([1, 2, 2, 3]);
Returns: Array — Array with unique values
sum(arr) arr: Array<number>
Calculates the sum of all numbers in the array.
Example 
const total = sum([1, 2, 3, 4]);
Returns: number — Sum of array elements
average(arr) arr: Array<number>
Calculates the average (mean) of all numbers in the array.
Example 
const avg = average([1, 2, 3, 4]);
Returns: number — Average value
clamp(value, min, max) value: number, min: number, max: number
Clamps a value between a minimum and maximum range.
Example 
const clamped = clamp(15, 0, 10);
Returns: number — Clamped value
randomBool()
Returns a random boolean value (true or false).
Example 
const flag = randomBool();
Returns: boolean — Random boolean
